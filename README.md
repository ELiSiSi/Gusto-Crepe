# Gusto-Crepe

الموقع الرسمي والرابط الذكي لمطعم **Gusto Crepe (جوستو كريب)** - ميت غمر.

> "أي حد بيعمل كريب … بس مش أي حد جوستو" 🥐🇫🇷

## المميزات:
- تصميم متجاوب 100% مع جميع شاشات الهواتف وأجهزة الكمبيوتر.
- ألوان وهوية مطابقة للوجو (اللبني والأحمر الكريمسون).
- خلفية دودل مخصصة للكريب والمطعم.
- قائمة طعام رقمية (6 صفحات) بدقة عالية مع ميزة التكبير والتصفح الكامل (Lightbox Zoom).
- روابط مباشرة وسريعة للطلب عبر الواتساب والاتصال.
- صفحة الموقع واللوكيشن المباشر على خرائط جوجل (Google Maps).
